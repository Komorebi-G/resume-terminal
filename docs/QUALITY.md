# 质量与验收记录

当前交付为 0.1.5 开发版。本轮重点是 Linux 用户目录配套安装、临时 shell 回退和失败恢复。验证覆盖下列明确范围，不代表所有 Linux 环境、代理或权限组合都已实测。原始运行日志与截图留在本机，不随源码发布。

## 2026-10-03 终端文字与框线间距修正

本次工作区维护针对终端文字排版，保留原字号和行距默认值。Android 对单个字符的宽度测量不包含字距；此前只测 `X` 作为列宽，字距设置会让整段文字展开，但列数、光标和选区仍使用原网格。现在字距进入列宽计算，文字按完整绘制段测量；中文和其他窄回退字形保留原比例，在所属格子中居中，过宽字形才缩小。常见单线、粗线和圆角框线按格子边界绘制，使调整行距和字距后接缝仍连续。其他框线字符继续使用字体字形。

新增 8 项原生 Canvas 像素回归：字距与列宽、中文比例、ANSI 颜色分段、不同间距的纵向接缝、横向接缝、圆角接缝、高亮背景范围、竖线光标下的字形。JVM 回归 app 168、terminal-emulator 152、terminal-view 17，共 337 项通过；同样的 8 项像素检查在 Windows 原生 Android API 35 模拟器上通过。标准 debug APK 构建成功，lint 0 错误、52 警告，本次渲染文件无 lint 问题。实际手机上的观感仍需安装测试包确认。

## 0.1.5 Linux 配套安装与复查

- 缺配套仍可进入临时 SSH shell；安装入口只出现在持久终端面板，用户点击后才写远端。使用单独 SSH exec 通道，不向现有 shell 注入命令；安装后明确引导新建持久终端，不自动转换现有任务。
- Linux x86_64 / ARM64 固定版本下载、HTTPS 与 SHA-256 校验，当前用户目录安装，无需 sudo，不修改 SSH、网络、系统服务或 shell 配置。电脑入口使用通用 sh。已有可运行 zmx 被复用，其他 remote-work 命令不会被覆盖。
- 复查修复：启动/附加失败后实际终端回调清除持久身份，重连不复用失效的启动命令；探测、管理命令使用 sh，手机附加清除继承的 ZMX_SESSION；新二进制和电脑入口先准备、验证，再发布，避免入口写入失败仍显示配套就绪。

安装结果丢失时不会直接当作成功或确定失败：提示刷新，实际探测就绪后才能新建持久终端。阶段提交不等于跨文件系统事务；发布第二部分失败仍会明确报错，可重试，不修改或终止已有持久进程。

ARM64 的官方下载包校验值和脚本选择逻辑已核对，尚未在 ARM 主机执行。没有覆盖所有发行版、代理/证书、NFS/noexec、SSH 限制策略、实机网络切换及系统重启组合。无法连接 SSH 的主机仍需在电脑端先开启 SSH；配套不能让进程跨主机关机继续运行。

可复跑的实际测试：

```sh
python3 scripts/test-linux-companion.py
# 需要在独立 Python 环境安装 paramiko，并先将 app/test APK 安装到模拟器。
python3 scripts/test-companion-ssh.py --adb /path/to/adb --all --output /tmp/companion-ssh.txt
```

## 构建边界

标准 debug 构建面向 Android 7.0+ ARM64 手机。SSH 是本分支的主要验证路径；mosh 原生客户端需通过 `scripts/build-mosh-native.sh` 构建，标准源码构建不会自动下载该二进制。字体扩展变体另见 `scripts/fetch-maple-font.sh`。不沿用上游的发布签名或自动更新源。

实体手机输入法手感、Wi-Fi / 移动数据切换、后台保活及 ARM Linux 主机运行仍需进一步实测。
