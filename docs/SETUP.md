# 安装与使用

## 分享给朋友或连接其他 Linux 主机

APK 支持 Android 7.0 及以上，目前仅提供 ARM64 手机包。包内没有你的连接、密码或主机配置；朋友需要添加自己的主机。

1. 被控主机先安装并开启 SSH，手机能到达该主机的地址和端口，并有可登录的账户。虚拟机需桥接网络或端口转发；双系统需正在运行 Linux。App 无法在 SSH 尚未开放时远程配置它。
2. 连接后，即使没有配套，也可使用临时 shell。缺少配套会短暂提示，安装入口一直保留在顶部“持久终端”面板；用户主动点击“安装并启用”才开始写入远端。
3. 自动安装面向 Linux x86_64 / ARM64：主机从 zmx.sh 下载固定的 zmx 0.8.1，进行 SHA-256 校验。只写当前 SSH 用户目录，无需 sudo，不改 SSH、网络或 shell 启动文件。
4. 新安装的二进制位于 `~/.local/share/resume-terminal/bin/zmx`；电脑入口位于 `~/.local/bin/remote-work`，状态目录为 `~/.local/state/resume-terminal/zmx`（权限 0700）。已有能运行的 zmx 会被复用；不覆盖其他来源的同名 remote-work 命令。
5. 安装完成后在面板新建持久终端，或选择电脑创建的终端。当前临时 shell 和其中的程序不会被搬进去；可以先完成或妥善结束临时 shell 中的任务。

主机需要通用 `sh` 和基本文件命令；首次下载还需要 curl、tar、gzip，以及 sha256sum 或 shasum。缺工具、下载/校验失败、目录无权限、磁盘满、二进制无法运行、架构不支持等会显示原因并允许重试。不会自动提权安装系统软件。SSH 返回结果丢失时先刷新检查，避免把“结果没收到”当成“肯定没装好”。

电脑端也可以从源码目录执行同一份安装脚本：

```sh
sh app/src/main/assets/companion/install.sh
# 兼容入口：sh wsl/install.sh
~/.local/bin/remote-work 项目名
```

手机断线与主机关机不同：持久终端能处理客户端断线，不能跨主机关机、虚拟机停止或双系统切换保存正在运行的进程。

## 填写自己的连接参数

| 手机连接字段 | 内容 |
|---|---|
| 主机 | 手机可到达的 Linux 主机 IP 或域名 |
| 端口 | SSH 实际监听端口，常见为 22；端口转发时填写外部端口 |
| 用户名 | Linux 上已存在、允许 SSH 登录的账户名 |
| 认证 | 该账户的密码，或已授权的 SSH 私钥 |
| 持久化 | 持久终端；缺配套时可继续使用临时 shell |
| mosh | 当前分支优先验证 SSH；mosh 另需原生库、服务端及 UDP 网络 |

首次连接时，在主机上用 `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` 核对相应主机密钥的指纹。密码是 Linux 账户密码，与 Windows PIN 无关；App 不预置或创建凭据。密钥认证需要导入私钥内容。

WSL、虚拟机和双系统都需要独立确认 SSH 与网络可达。Tailscale 等组网工具是可选的网络方案，需要自行安装配置，不由 App 自动配置。使用桥接、NAT 或端口转发时，应按实际网络填写地址。

## 装 APK

构建产物：`app/build/outputs/apk/standard/debug/app-standard-debug.apk`。将它传到手机，在文件管理器中打开并安装“续端”。只在系统提示时给此次安装来源开启安装权限。

安装后填写自己的连接；“持久终端”已经是新连接的默认值。选择电脑端启动的终端即可继续工作。顶部终端入口可以刷新和切换其他终端。

## 电脑端使用

```bash
cd ~/projects/你的项目
remote-work 项目名
codex
```

第一次创建的终端从当前目录开始。之后同名入口恢复已有现场，不会按新的目录或程序参数重开。

```bash
remote-work                 # 列表选择已有终端，或输入新名称
remote-work --list          # 只列出
remote-work 文档             # 中文名称可用
remote-work scratch codex   # 新终端直接运行 codex；codex 退出后该终端结束
```

建议在持久 shell 里启动 Codex/DSH，程序退出后仍可继续用 shell。终端名称不能含路径分隔符、控制字符或以短横线开头，UTF-8 长度上限为 64 字节。

同一终端可同时连电脑和手机，输入共享；显示会按 zmx 当前活动客户端的尺寸调整。切换手机横竖屏、弹收键盘会改变终端行列数。

## 命令输入与 Codex

底部编辑按钮打开紧凑输入栏；Tab、Ctrl、Alt、Shift、方向键仍在输入栏下面。

- 输入 `cd /home/l` 后点 Tab：先将文字送到远端再补全；补全结果显示在终端里。输入栏清空后，可以继续输入路径后缀，或直接按键盘发送键 / 箭头执行。
- 输入栏为空时，软键盘退格作用于远端命令；中文候选和未送出的本地文字先在输入栏里编辑。
- Ctrl / Alt / Shift 点一次只作用于下一键，再点取消；长按锁定，出现小锁，再点取消锁定。例如 Ctrl 后输入 C 就打断任务。
- 方向键、退格、删除与翻页键支持长按连发；更多面板中的 Ctrl+W / Ctrl+U / Ctrl+R 可用于删词、删整行和搜索历史。
- 常驻常用键默认是 Shift+←，从“更多 → 全部按键 → 常用键”可更换并自动保存；Ctrl、Alt、Shift 始终常驻。Shift+← / →、Alt+↑ / ↓ 和 Shift+Tab 不会送出本地草稿，方便先切换问题或模式。Ctrl+C / Esc 会丢弃未发送草稿并将控制键送到远端。
- 输入栏左边的编辑图标展开多行；多行文本粘贴会自动展开。键盘回车用于换行，右边箭头发送正文后再回车；“发送”只插入正文。发送尊重远端的 bracketed paste 模式，中文与英文按 UTF-8 传输。
- 发送后输入栏继续保持打开；关闭输入栏会保留草稿，回到直接终端输入。

### 常驻两排与“更多”

默认两排保持 7 列，不横向滚动：

```text
Esc   Ctrl   Alt   ↑   Shift   ⇧←   更多
Tab   粘贴    ←     ↓   →       中断  输入栏
```

- 修饰键加方向键可组合出 Shift+←、Alt+↑、Ctrl+← 等，常用键变化时不必升级 APK。
- 原来的 `⇧Tab` 是 Shift+Tab；现在点击 Shift 再点 Tab 即可。腾出的常驻位置用来粘贴。
- 唯一的常用键位置可以设为 Shift+← / →、Alt+↑ / ↓、Home、End、Ctrl+R、Alt+Enter、Shift+Enter、`/model` 或 `/resume`。选择保存到 App 设置，所有连接共用。
- “更多”默认显示 Codex 命令、8 个编辑导航键和 7 个常用 Ctrl 键；点“全部按键”再看其他控制键、F1–F12 和常用键设置。每次打开先显示精简面板；已常驻的 MODEL / RESUME 不会在面板重复。内容可纵向滚动，修饰键仍在面板下方。
- Home / End、Ins / Del、退格、Enter、PgUp / PgDn 均可从面板进入；Ctrl+A/E/U/K/W/Y/L/D/Z/R/P/N/B 等常用操作有单键入口，其他 Ctrl/Alt+字母可用修饰键加屏幕键盘输入。
- 修饰键加面板里的 Enter，或将常用键设为 Shift+Enter，可发送独立 CSI-u 编码，不再退化为普通回车。远端程序需要支持该编码；旧程序可尝试 Alt+Enter。当前没有宣称完整支持 kitty 键盘协议的协商和全部组合。

### Codex 命令入口

“更多”里的 `/model` 用于模型与思考强度选择，`/resume` 用于恢复 Codex 对话；它与顶部恢复 WSL 持久终端是两种操作。命令含义依据 [OpenAI 官方 CLI 文档](https://learn.chatgpt.com/docs/developer-commands?surface=cli)，是否提供某种强度由当前模型和 Codex 版本决定。

按钮只把命令放进输入栏，不自动回车；确认远端处于 Codex 输入状态后按发送。已有本地草稿会保留，点“草稿已保留 · 恢复”取回。若已保留一份草稿且又输入了新的文字，会要求先发送或清空当前输入，避免覆盖第二份草稿。

本地输入栏不是远端 readline / Codex 输入框的完整镜像。送出文字后，可用方向键、退格、Ctrl 组合编辑远端内容；需要直接输入时，关闭输入栏即可。

### 复制、粘贴与中断

- 长按终端输出，拖动选区手柄，再点浮动工具条或常驻行的“复制”。草稿栏打开时也能选择输出，复制保留草稿。
- 有输出选区或本地草稿选区时，常驻“中断”键改为“复制”。复制只操作手机剪贴板，不发送 Ctrl+C。
- 外接键盘 Ctrl+C：有选区则复制；无选区则发送 Ctrl+C，中断当前远端任务。Ctrl+Shift+C 专门复制，没选中文字时不做操作。按住复制快捷键不会在选区消失后意外发送中断。
- 常驻“粘贴”、Ctrl+V、Ctrl+Shift+V、输出区浮动工具条的粘贴和鼠标中键都使用同一条粘贴路径。剪贴板没有文字时会提示。Ctrl+V 已用于手机剪贴板，不再向远端发送字面控制码 `0x16`。
- 输入栏打开时，在光标处插入，或替换本地选区，不自动发送。粘贴会清除附加键 Ctrl/Alt/Shift 状态，避免下一字被当成控制键。
- 直接终端模式的单行粘贴发送正文，不额外回车；多行或带末尾换行的文本会先打开草稿栏，检查后再发送。保留制表符和换行，过滤粘贴内容里的 Ctrl+C、Ctrl+D、Esc 等控制字符。
- 远端支持 bracketed paste 时发送对应包裹序列；“发送”多行草稿时，旧终端仍可能把换行当作执行，请在草稿里检查命令。
- 外接键盘编辑本地草稿时，Ctrl+A 全选，Ctrl+X 剪切选区，Ctrl+Z/Y 撤销/重做交给本地文本框；Ctrl+C/V 用于本地复制粘贴。输入栏为空时，Ctrl+C 和行编辑组合仍可操作远端。

## 区分断开与结束

- 关闭客户端窗口、手机“断开连接”：远端程序继续运行。
- 列表“关闭”：结束选定终端及其程序，会要求再次确认。
- shell 中输入 `exit`：结束该 shell。
- Windows 重启、WSL 关闭或进程崩溃：内存中的程序现场不能保留。电脑休眠时无法远程连接，恢复供电和网络后才能重连。

## 首次确认流程

1. 电脑运行 `remote-work phone-check`，输入 `echo $$`，记录 PID。
2. 在这个 shell 里启动 Codex 或 DSH，留一个正在输入的现场。
3. 手机进入 `phone-check`，检查现场，输入中文、英文、Tab 和当前 Codex 使用的组合键。
4. 关闭手机连接，再进同名终端；检查程序和内容没有重新启动。
5. 测试 Wi-Fi 与移动数据切换、关屏再打开、横竖屏与键盘弹收。
6. 中文候选词未提交时按退格，确认不会删除远端已输入的命令。

## 连接异常

在 Windows PowerShell 查看转发：

```powershell
& 'C:\Program Files\Tailscale\tailscale.exe' serve status
```

如需自行配置一个 SSH TCP 转发，可参考（按自己的服务地址与端口调整）：

```powershell
& 'C:\Program Files\Tailscale\tailscale.exe' serve --bg --tcp=2222 tcp://localhost:22
```

在 WSL 检查 SSH 与终端：

```bash
systemctl is-active ssh
remote-work --list
```

列表为空时先检查电脑端是否通过 `remote-work` 开启；普通 shell 或直接使用其他 ZMX_DIR 的 zmx 会话不会出现在这个产品的列表中。连接断开但列表仍有终端，选择它即可恢复。远端没装配套程序时，应用会明确提示安装。

官方资料：[Tailscale Serve](https://tailscale.com/docs/reference/tailscale-cli/serve)、[zmx](https://github.com/neurosnap/zmx)。

## 收起与返回

终端页的顶部返回先收起按键面板，再取消输出选区、收起草稿栏，最后才离开终端；系统返回在键盘隐藏后遵循同样顺序。收起草稿不丢文字，再打开可继续编辑。返回会清除附加键修饰状态，避免回到直接输入后意外带着 Ctrl。
